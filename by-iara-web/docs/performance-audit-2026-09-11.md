# Public website performance audit — 2026-09-11

## Executive summary

This audit covers every discoverable, non-legal public route of the production website. The authoritative production origin is `https://iaragouveia.com`: the supplied `iaragouveia.com.pt` hostname did not resolve, and the supplied PageSpeed report itself targeted `https://iaragouveia.com/pt`.

The most important production problems were unstable layout on the massage catalogue and guides pages, a 3.49 MiB homepage payload caused by both hero-video encodes being downloaded, seven uncompressed TTF font transfers, and images delivered substantially larger than their rendered size. The implementation in this change addresses the shared causes rather than patching individual routes:

- the browser now loads exactly one supported hero-video format and no video for a reduced-motion visit until explicit playback;
- responsive AVIF sources were added for the homepage LCP still, studio image, and packs hero, with the existing assets retained as fallbacks;
- seven TTF files were replaced by equivalent WOFF2 subsets, reducing their repository bytes from 563,516 to 140,412 (75.1%);
- the footer logo now has explicit intrinsic and rendered dimensions;
- synchronous header layout measurement was removed from the render path;
- the small-screen header grid reserves balanced space around the centered logo.

Accessibility and Best Practices were already 100 on every production route tested and were preserved. Production SEO was 100 except for the two booking routes, where PageSpeed scored 69 because the pages used `noindex, follow`. A subsequent booking-specific SEO review confirmed that these are useful public conversion pages with complete SSR content, so they are now indexable while personalized query variants remain consolidated to the clean canonical URLs.

## Implementation and architecture notes

The changes stay inside existing lazy feature boundaries and shared theme/app-shell ownership. No new runtime dependency or one-off route workaround was introduced. Brand typography, colors, content, video experience, interaction model, localized URL strategy, structured SEO behavior, and API contracts remain intact.

Production build output after the change is 506.60 KiB raw/131.42 KiB estimated transfer for initial browser chunks, effectively flat versus the 506.48 KiB/131.31 KiB baseline. The existing initial bundle warning (6.60 KiB above the 500 KiB budget) and existing component-style warnings for home, booking, and the internal design-system view remain; none was introduced materially by this work.

The repository mentions an Nx MCP server as an optional development tool. No Nx MCP endpoint was available in this execution environment, and the site contains no runtime WebMCP integration. This does not block the audit or alter public performance. PageSpeed's experimental “Agentic Browsing” category is distinct from the four scored categories and provides no justification for adding a client-side runtime solely for the audit.
