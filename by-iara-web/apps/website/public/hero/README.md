# Home hero media

`hero-studio-massage-2026-09.webm` is the primary web encode of the supplied
studio massage hero clip. It is a silent VP9 WebM at 1280×720 and 30 fps.
`hero-studio-massage-2026-09.mp4` is the H.264 compatibility fallback.

`hero-studio-massage-2026-09.jpg` is the matching opening-frame poster. Keep the
video and poster together when replacing this media so the first paint, autoplay
fallback, and reduced-motion experience remain visually consistent. Use a new
descriptive filename for each replacement because production serves static assets
with a one-year browser cache. The poster is also the default social preview and
the backdrop on secondary pages.
