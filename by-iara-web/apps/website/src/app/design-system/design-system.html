Research notes

Rules we are adopting

These are the external guidelines behind the tokens. Keep this section updated when the design system changes.

60-80 characters with roughly 1.5-1.6 line height for desktop reading. Body text should stay near 50-75 characters per line. Use baseline grids, padding, keylines, and incremental spacing for layout rhythm. Place buttons with enough visual and target spacing for comfortable selection. WCAG contrast targets: 4.5:1 for normal text and 3:1 for large text or UI indicators.
