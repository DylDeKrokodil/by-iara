Fills vs. text

The one rule that keeps pink readable

Bright rose is a fill color, not a text color. Fill buttons and chips with --primary; write pink text with --primary-strong.

Fills — --primary

Rose carries the action

Buttons, active tabs, selected chips and section drenches use the bright fill with white text on top.

Support — --accent

Green grounds it

A deep eucalyptus green stands in for the camellia's stem — used sparingly for accents, never for a primary action.
